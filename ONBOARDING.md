# ONBOARDING – Sprint Excellence 2025

Bienvenue dans l’équipe Velo-Altitude !

## Étapes clés pour bien démarrer

1. **Lire la documentation essentielle**
   - [README.md](./README.md)
   - [CONTRIBUTING.md](./CONTRIBUTING.md)
   - [TEAM_GUIDE.md](./TEAM_GUIDE.md)
   - [FAQ.md](./FAQ.md)

2. **Cloner le repo et installer les dépendances**
   - `git clone ...`
   - `npm install` (client et server)

3. **Comprendre la structure du projet**
   - Données : `/server/data/`, `/public/images/`
   - Frontend : `/client/`
   - Backend : `/server/`

4. **Lancer le projet en local**
   - `npm run dev` (ou voir Procfile pour les commandes spécifiques)

5. **Respecter les bonnes pratiques**
   - Qualité, documentation, tests, validation automatisée
   - Proposer des idées d’innovation à chaque sprint
