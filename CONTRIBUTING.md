# CONTRIBUTING – Sprint Excellence 2025

## Philosophie

L’amélioration continue et l’innovation sont au cœur du projet Velo-Altitude. Toute contribution doit viser l’excellence technique, la qualité des données, la performance et l’expérience utilisateur.

## Nouveautés 2025

- Enrichissement massif des données (cols, trainings, nutrition)
- Documentation technique structurée et systématiquement à jour
- Automatisation : scripts pour import, validation, tests
- Focus sur l’innovation (3D, IA, mobile, communauté)
- Monitoring et reporting intégrés

## Bonnes pratiques

- Forkez le repo, créez une branche descriptive (ex: `feature/col-explorer-3d`)
- Documentez chaque PR (objectifs, impacts, tests)
- Respectez la structure des données (voir MIGRATION.md et API_DOCUMENTATION.md)
- Exécutez les scripts de validation et tests avant toute PR
- Corrigez tous les lints (Markdown, JS, JSON)
- Ajoutez des exemples d’utilisation et des cas limites dans la documentation

## Processus de contribution

1. Ouvrez une issue pour toute proposition majeure
2. Décrivez précisément vos changements dans la PR
3. Assurez-vous que la documentation et les tests sont à jour
4. Demandez une review à un membre lead
5. Suivi du merge et reporting dans PROGRESS_REPORT_S1.md
