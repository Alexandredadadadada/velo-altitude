# USAGE_GUIDE – Sprint Excellence 2025

## Accès et navigation
- Accédez à l’application via l’URL locale ou déployée (voir README.md)
- Utilisez la barre de recherche pour trouver un col, un programme, ou une recette
- Profitez du Col Explorer 3D pour une expérience immersive

## Fonctionnalités principales
- **Cols enrichis** : profils détaillés, météo, records, images, galerie communautaire
- **Programmes d’entraînement** : filtres par niveau, durée, type (HIIT, spécifique col…)
- **Nutrition** : recettes adaptées à chaque phase, recommandations IA
- **Dashboards admin** : suivi des performances, erreurs API, activation de features
- **Mode mobile basse consommation** : activez-le dans les paramètres

## Conseils d’utilisation
- Créez un compte pour sauvegarder vos favoris et suivre vos progrès
- Participez au challenge photo pour enrichir la galerie des cols
- Signalez tout bug ou suggestion via l’issue tracker
